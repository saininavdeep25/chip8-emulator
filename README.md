# Chip-8 Emulator

A fully functional Chip-8 emulator written in C++. This project aims to accurately emulate the classic Chip-8 virtual machine, allowing you to run and play original Chip-8 games and programs.

## About Chip-8

Chip-8 is an interpreted programming language, developed in the 1970s, designed to make it easier to program games on early microcomputers. It is known for its simplicity and is commonly used as a beginner’s project for emulator development.

## Features

- Accurate emulation of all Chip-8 opcodes
- Keyboard input mapping
- Graphics rendering (64x32 monochrome display)
- Sound support
- Step-by-step debugging
- Portable codebase
